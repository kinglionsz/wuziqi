# 五子棋后端服务器环境变量配置

## 重要：必须设置以下环境变量

由于 CloudBase CLI 不支持直接设置环境变量，请通过**腾讯云 CloudBase 控制台**手动配置：

### 操作步骤

1. 访问：https://console.cloud.tencent.com/tcb/cloudrun
2. 选择环境：`codebuddy-9gu42kpn62ead2e2`
3. 服务列表 → 点击 `wuziqi-server`
4. 点击 **版本管理** 标签
5. 点击当前版本右侧的 **编辑** 按钮
6. 找到 **环境变量** 区域，点击 **添加**
7. 依次添加以下变量：

| 变量名 | 值 | 必填 |
|--------|-----|------|
| `ALLOWED_ORIGIN` | `https://codebuddy-9gu42kpn62ead2e2-1402693592.tcloudbaseapp.com` | ✅ 必填 |
| `TCB_ENV_ID` | `codebuddy-9gu42kpn62ead2e2` | ✅ 必填 |
| `NODE_ENV` | `production` | ✅ 必填 |
| `PORT` | `3000` | 可选（默认值） |

8. 点击 **保存**，然后点击 **部署** 使配置生效

### 验证配置

部署完成后，访问部署日志查看：
- 确认日志中显示：`[配置] CORS origin: https://codebuddy-9gu42kpn62ead2e2-1402693592.tcloudbaseapp.com`
- 确认 **没有** `[安全警告] 未配置 ALLOWED_ORIGIN` 警告

| 变量名 | 值 |
