# 五子棋游戏后端 - 架构与部署说明

## 📋 项目概述

- **项目名称**：五子棋在线对战服务器
- **版本**：v1.2.7
- **技术栈**：Node.js + Express + Socket.io
- **部署平台**：Railway
- **运行环境**：Node.js 18+

---

## 🏗️ 项目架构

### 1. 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| **运行时** | Node.js | 20 |
| **Web 框架** | Express | ^4.18.2 |
| **WebSocket** | Socket.io | ^4.7.2 |
| **跨域支持** | CORS | ^2.8.5 |
| **模块类型** | ES Modules | - |

### 2. 项目结构

```
railway-backend/
├── server.js              # 主服务器文件（包含所有逻辑）
├── package.json           # 项目依赖配置
├── Dockerfile             # Docker 构建文件
└── railway.json           # Railway 部署配置
```

### 3. 核心功能模块

#### 3.1 游戏逻辑层

| 功能 | 说明 |
|------|------|
| **胜负判断** | `checkWinner()` - 检测五子连珠 |
| **平局检测** | `checkDraw()` - 棋盘满且无胜负 |
| **落子验证** | `validateMove()` - 验证位置是否合法 |
| **房间管理** | `createRoom()` - 创建游戏房间 |
| **ID 生成** | `generateRoomId()` - 生成 6 位房间号 |

#### 3.2 网络通信层

| 事件 | 方向 | 说明 |
|------|------|------|
| `create_room` | 客户端→服务端 | 创建房间 |
| `join_room` | 客户端→服务端 | 加入房间 |
| `place_piece` | 客户端→服务端 | 下棋 |
| `leave_room` | 客户端→服务端 | 离开房间 |
| `restart_game` | 客户端→服务端 | 重新开始 |
| `game_start` | 服务端→客户端 | 游戏开始 |
| `sync_board` | 服务端→客户端 | 同步棋盘 |
| `game_over` | 服务端→客户端 | 游戏结束 |
| `opponent_disconnected` | 服务端→客户端 | 对手断开 |
| `room_closed` | 服务端→客户端 | 房间关闭 |

#### 3.3 房间状态管理

```javascript
Room {
  roomId: string,              // 房间 ID
  players: {                   // 玩家映射
    [socketId]: {
      role: 'black' | 'white', // 角色
      ready: boolean            // 准备状态
    }
  },
  board: number[][],            // 15×15 棋盘
  currentTurn: 'black' | 'white', // 当前回合
  status: 'waiting' | 'playing' | 'finished', // 房间状态
  moveHistory: Array<{        // 走棋历史
    player: string,
    position: { row, col },
    timestamp: number
  }>
}
```

## ⚠️ 常见问题

### 1. 部署失败 - 端口占用

**错误**：`Error: listen EADDRINUSE: address already in use`

**原因**：端口 `3000` 被占用

**解决方案**：
```bash
# 方法 1：修改环境变量
# 在 Railway 设置中设置 PORT=8080

# 方法 2：修改代码
const PORT = process.env.PORT || 8080
```

### 2. WebSocket 连接失败

**错误**：客户端无法连接 Socket.io

**原因**：
- CORS 配置错误
- 前端连接地址错误
- 防火墙拦截

**解决方案**：
```javascript
// 检查 CORS 配置
const io = new Server(httpServer, {
  cors: {
    origin: '*', // 或指定前端域名
    methods: ['GET', 'POST']
  }
})

// 前端连接确保使用正确地址
const socket = io('https://wuziqi-backend.railway.app', {
  transports: ['websocket', 'polling']
})
```

### 3. 房间 ID 冲突

**错误**：多个玩家创建相同房间 ID

**原因**：随机生成算法概率冲突

**解决方案**（已实现）：
```javascript
let roomId = generateRoomId(6)
while (rooms[roomId]) {  // 循环直到唯一
  roomId = generateRoomId(6)
}
```

### 4. 玩家断开后状态残留

**错误**：断开连接后房间仍占用内存

**原因**：未正确清理 `socketToRoom` 映射

**解决方案**（已实现）：
```javascript
socket.on('disconnect', () => {
  const roomId = socketToRoom[socket.id]
  if (roomId && rooms[roomId]) {
    // 清理玩家
    delete rooms[roomId].players[socket.id]
    // 房间空时删除
    if (Object.keys(rooms[roomId].players).length === 0) {
      delete rooms[roomId]
    }
  }
  delete socketToRoom[socket.id]
})
```

### 5. 构建超时

**错误**：Railway 构建超时

**原因**：依赖安装时间过长

**解决方案**：
```dockerfile
# 优化 Dockerfile
FROM node:20-slim
WORKDIR /app

# 复制依赖文件
COPY package*.json ./

# 使用国内镜像加速
RUN npm config set registry https://registry.npmmirror.com && \
    npm install --production

COPY . .
EXPOSE 3000
CMD ["node", "server.js"]
```

### 6. 跨域问题

**错误**：浏览器报错 CORS 策略阻止

**原因**：CORS 配置过于宽松或错误

**解决方案**：
```javascript
// 生产环境限制域名
const io = new Server(httpServer, {
  cors: {
    origin: [
      'https://wuziqi-frontend.railway.app',
      'http://localhost:5173'  // 开发环境
    ],
    credentials: true
  }
})
```

### 7. 内存泄漏

**错误**：长时间运行后内存增长

**原因**：未清理断开连接的 Socket

**解决方案**：
```javascript
// 添加心跳检测
io.on('connection', (socket) => {
  socket.on('ping', () => socket.emit('pong'))
  
  // 10 分钟无活动则断开
  let timeout = setTimeout(() => socket.disconnect(), 600000)
  
  socket.on('any', () => {
    clearTimeout(timeout)
    timeout = setTimeout(() => socket.disconnect(), 600000)
  })
})
```

### 8. 部署后访问 404

**错误**：健康检查返回 404

**原因**：Express 路由未正确配置

**解决方案**：
```javascript
// 确保在 socket 之前定义路由
app.get('/', (req, res) => res.send('OK'))
app.get('/health', (req, res) => res.json({ status: 'ok' }))

// 然后再启动 Socket.io
const httpServer = createServer(app)
const io = new Server(httpServer, {...})
```
