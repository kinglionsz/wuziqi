# 五子棋游戏 (Gomoku)

一个精美的在线五子棋游戏，支持人机对战、双人对战等多种模式。

## 功能特性

### 游戏模式
- **双人对战** - 本地双人对战模式
- **人机对战** - 与内置 AI 对战
- **在线对战** - 创建/加入房间（开发中）

### AI 智能对手
- 内置启发式评分算法
- 智能攻守判断
- 优先占据中心位置

### 个性化
- **6种主题**：默认、木纹、海洋、森林、夜空、樱花
- **音效系统**：落子音效、胜利音效（可开关）
- **游戏记录**：自动保存到本地存储
- **回放功能**：查看对局过程

### 其他功能
- 最后落子高亮标记
- 悔棋功能
- 倒计时显示
- 胜负判定

## 技术栈

- **前端框架**: React 19
- **构建工具**: Vite 7
- **部署平台**: 腾讯云 CloudBase

## 游戏规则

1. 黑白双方轮流在棋盘上落子
2. 黑棋先行
3. 率先在一条直线（横、竖、斜）上连成五子的一方获胜
4. 棋盘下满无子可落且无一方获胜，则为平局
