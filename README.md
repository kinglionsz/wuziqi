# 五子棋游戏 (Xiaochidian Chess Game)

React + Vite 构建的五子棋游戏

## 功能特性

- **AI 对战**：内置智能 AI对手，支持简单/中等/困难三种难度
- **双人对战**：本地双人对战模式
- **在线对战**：支持创建/加入房间（开发中）
- **音效系统**：落子音效、胜利音效、可开关
- **主题切换**：6种精美主题（默认、木纹、海洋、森林、夜空、樱花）
- **游戏记录**：自动保存游戏记录到本地
- **回放功能**：支持查看对局回放
- **最后落子标记**：高亮显示最后一步
