项目概述

本项目是一个功能完整的五子棋在线游戏，采用前后端分离架构，支持三种游戏模式：PVP PVE 在线对战。使用 React + Vite 构建前端，Node.js + Express + Socket.io 构建后端服务，部署于腾讯云 CloudBase 平台。

🔄 回放模式优化 (v1.2.3)

新功能概述

本次更新为回放模式添加了专业级的苹果风格毛玻璃效果，并实现了可拖拽的模态框移动功能。

毛玻璃效果特点

  • 背景模糊 - 使用 backdrop-filter: blur(12px) saturate(180%)
  • 透明度层 - rgba(255, 255, 255, 0.45) 半透明背景
  • 边框高光 - 细微的白色边框模拟玻璃边缘
  • 多层阴影 - 柔和的阴影创造深度感
  • 光泽动画 - 微妙的扫过光效

拖拽功能

  • 桌面端 - 鼠标拖拽标题栏移动模态框
  • 移动端 - 触摸拖拽支持，优化的触摸事件处理
  • 平滑动画 - 拖拽时无动画，释放时有缓动效果
  • 位置记忆 - 打开时自动居中

CSS 样式 (App.css)

.modal-content {
  background: rgba(255, 255, 255, 0.45);
  backdrop-filter: blur(12px) saturate(180%);
  -webkit-backdrop-filter: blur(12px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.3);
  border-radius: 20px;
  box-shadow: 
    0 25px 50px -12px rgba(0, 0, 0, 0.4),
    0 0 0 1px rgba(255, 255, 255, 0.1) inset;
}

React 组件 (ReplayModal.jsx)

// 拖拽状态管理
const [position, setPosition] = useState({ x: 0, y: 0 })
const [isDragging, setIsDragging] = useState(false)

// 支持鼠标和触摸
const getClientPosition = (e) => {
  if (e.touches?.[0]) {
    return { x: e.touches[0].clientX, y: e.touches[0].clientY }
  }
  return { x: e.clientX, y: e.clientY }
}

// 拖拽事件处理
const handleStart = (e) => {
  if (e.type === 'touchstart') e.preventDefault()
  const { x, y } = getClientPosition(e)
  setIsDragging(true)
  setDragOffset({ x: x - position.x, y: y - position.y })
}

🚀 部署指南

前端部署

# 构建生产版本
npm run build

# 部署到 CloudBase
npx cloudbase hosting:deploy dist -e codebuddy-9gu42kpn62ead2e2

后端部署

# 进入后端目录
cd cloudbase/server

# 部署到 CloudRun
tcb cloudrun deploy -s wuziqi-server --port 3000 --source . --force

环境变量配置

# .env.production 示例
VITE_SUPABASE_URL=https://xxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIs...
NODE_ENV=production
ALLOWED_ORIGIN=*

注意： 部署前请确保已配置正确的环境变量，包括 Supabase API Key 和 CloudBase 配置。

❓ 常见问题

Q1: 如何开始游戏？
打开游戏后，选择三种游戏模式之一：PVP（双人本地对战）、PVE（人机对战）或 ONLINE（在线对战）。选择后即可开始游戏。
Q2: 如何进行在线对战？
选择 ONLINE 模式后，可以选择"创建房间"生成房间号发送给朋友，或输入房间号"加入房间"与朋友对战。
Q3: 如何切换主题？
点击设置按钮，在主题选项中选择喜欢的皮肤：默认、木质、海洋、森林、夜间、粉色。
Q4: 游戏记录在哪里查看？
游戏结束后会自动保存记录到本地存储和云端，可以在设置中查看游戏历史记录。
Q5: 部署遇到问题怎么办？
请确保 Node.js 版本 >= 18.0.0，Docker 版本 >= 20.10.0。如遇问题，可查看控制台日志或联系技术支持。
Q6: 如何本地开发调试？
# 启动前端开发服务器
npm run dev

# 启动后端服务
cd cloudbase/server
node server.js
