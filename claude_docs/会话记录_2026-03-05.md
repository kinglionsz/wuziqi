### 3. 项目分析

#### 项目概述
五子棋 (Gomoku) 在线游戏项目

#### 游戏模式
| 模式 | 说明 |
|------|------|
| PVP | 本地双人对战 |
| PVE | 人机对战 (简单/中等/困难) |
| ONLINE | 在线对战 (WebSocket) |

#### 技术栈

**前端**:
- React 19
- Vite 7
- TailwindCSS 4
- Socket.io-client 4.7.2

**后端**:
- Node.js + Express 4.18.2
- Socket.io 4.7.2 (WebSocket 实时通信)

**数据库/云服务**:
- Supabase (PostgreSQL)
- 腾讯云 CloudBase (静态托管 + 云托管)

#### 项目结构
```
wuziqi/
├── src/                    # 前端源代码
│   ├── components/         # React 组件
│   ├── hooks/              # React Hooks
│   ├── lib/                # 第三方库封装
│   ├── utils/              # 工具函数
│   └── App.jsx             # 主应用组件
├── cloudbase/server/       # 后端云托管代码
├── .claude/                # Claude 配置
└── CLAUDE.md               # Claude 开发指引
```

#### 核心文件
| 文件 | 说明 |
|------|------|
| `src/App.jsx` | 游戏主组件 |
| `src/hooks/useGameLogic.js` | 核心游戏逻辑 Hook |
| `src/hooks/useOnlineGame.js` | 在线对战 Hook |
| `src/components/Board/Board.jsx` | 棋盘组件 |
| `cloudbase/server/index.js` | 后端 WebSocket 服务器入口 |

#### AI 算法
- **简单**: 随机落子 + 基础进攻
- **中等**: 攻防平衡，偶尔失误
- **困难**: Minimax + Alpha-Beta 剪枝
