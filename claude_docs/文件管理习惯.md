# 文件管理习惯与自动整理规则

本文档定义了五子棋项目的文件管理习惯，供 Claude Code / Code X 自动执行文件整理。

---

## 1. 备份/重复文件清理规则

### 必须删除的文件模式

| 模式 | 示例 | 说明 |
|------|------|------|
| `* copy*` | `App copy.jsx`, `useGameLogic copy.js` | 调试/备份文件 |
| `* 副本*` | `cloudbase - 副本/` | 中文备份文件夹 |
| `*_backup*` | `index_backup.js` | 带 backup 后缀 |
| `*-副本` | `file-副本` | 带"副本"后缀 |
| `.ts` + `.tsx` 同时存在 | `App.jsx` + `App.tsx` | 功能重复，保留一个 |
| `.js` + `.jsx` 同时存在 | `main.js` + `main.jsx` | 功能重复，保留一个 |

### 自动清理命令

```bash
# 查找备份文件
find . -name "*copy*" -o -name "*副本*" -o -name "*_backup*"

# 删除备份文件
find . -name "*copy*" -delete
```

## 3. 文件命名规范

### 强制规则

| 类型 | 规则 | 示例 |
|------|------|------|
| 组件 | `PascalCase.jsx` | `VictoryModal.jsx` |
| Hooks | `camelCase.js` | `useGameLogic.js` |
| 工具 | `camelCase.js` | `ai.js`, `sound.js` |
| 样式 | 与组件同名 `.css` | `Board.css` |
| 测试 | `*.test.js` 或 `*.spec.js` | `ai.test.js` |

### 禁止的命名

- ❌ `App.jsx` + `App.tsx` 同时存在
- ❌ `component.js` (应为 `.jsx`)
- ❌ `use_GameLogic.js` (应为 camelCase)

## 5. 自动整理检查清单

每次代码修改后，AI 应自动检查：

1. **是否存在新的备份文件？** → 删除
2. **是否有重复的功能文件？** → 保留一个，删除另一个
3. **文件命名是否符合规范？** → 不符合则提示用户
4. **新增文件是否应加入 .gitignore？** → 检查并添加
5. **是否有空目录？** → 删除

---

## 6. 常用清理命令

```bash
# 删除备份文件（当前目录）
Get-ChildItem -Recurse -Filter "*copy*" | Remove-Item -Force
Get-ChildItem -Recurse -Filter "*副本*" | Remove-Item -Force
Get-ChildItem -Recurse -Filter "*_backup*" | Remove-Item -Force

# 删除空目录
Get-ChildItem -Recurse -Directory | Where-Object { (Get-ChildItem $_.FullName -Force).Count -eq 0 } | Remove-Item -Force
```

---

## 7. 触发自动整理的时机

AI 应在以下时机主动检查文件整理：

1. 用户请求"整理"相关操作时
2. 完成代码修改并准备提交前
3. 检测到新的备份/重复文件时
4. 用户明确要求清理文件时

---

## 注意事项

- ⚠️ 删除文件前需确认不是唯一文件
- ⚠️ 保留最新的生产版本，删除旧备份
- ⚠️ 如果不确定，先询问用户再删除
