```bash

```

#### 3.4 CORS 问题解决
后端日志显示"未配置 ALLOWED_ORIGIN，CORS 将禁止所有跨域请求"

解决：启动后端时设置环境变量
```bash
ALLOWED_ORIGIN="*" npm run server
```

#### 3.5 端口占用问题解决
多次遇到端口占用，通过以下命令解决：
```cmd
netstat -ano | findstr 3000
taskkill //F //PID <PID号>
```

前端 vite.config.js 已配置 `host: '0.0.0.0'` 允许局域网访问
