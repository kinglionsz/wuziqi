## 1. 设计概述

### 1.1 目标

为五子棋游戏的**回放模式模态框**实现专业级毛玻璃效果，模仿苹果(Apple)网站的现代设计语言：

- **透明度与模糊**: 背景模糊 + 半透明层
- **深度层次**: 多层阴影创造立体感
- **流畅动画**: 平滑的过渡效果
- **交互反馈**: 拖拽移动功能

### 1.2 苹果毛玻璃设计特点

根据苹果官网设计风格，毛玻璃效果的核心要素：

| 特性 | 说明 | 实现方式 |
|------|------|----------|
| **背景模糊** | 使用 `backdrop-filter: blur()` | 模糊程度 6-20px |
| **透明度** | 半透明背景层 | `rgba(255,255,255, 0.1-0.5)` |
| **边框高光** | 细微的白色边框 | `border: 1px solid rgba(255,255,255,0.3)` |
| **阴影** | 柔和的多层阴影 | `box-shadow` 多层叠加 |
| **光泽感** | 微妙的渐变背景 | `linear-gradient` |

## 2. 代码实现

### 2.1 React 组件结构

**文件**: `src/components/Modals/ReplayModal.jsx`

```jsx
import React, { useState, useEffect, useRef } from 'react'

export const ReplayModal = ({ 
  isOpen, 
  moveHistory, 
  replayIndex,
  onClose,
  onReplayStep,
  onNextStep,
  onPrevStep
}) => {
  // 拖拽状态管理
  const [position, setPosition] = useState({ x: 0, y: 0 })
  const [isDragging, setIsDragging] = useState(false)
  const [dragOffset, setDragOffset] = useState({ x: 0, y: 0 })
  const modalRef = useRef(null)

  // 获取触摸/鼠标位置
  const getClientPosition = (e) => {
    if (e.touches && e.touches.length > 0) {
      return { x: e.touches[0].clientX, y: e.touches[0].clientY }
    }
    return { x: e.clientX, y: e.clientY }
  }

  // 拖拽事件处理 (支持鼠标 + 触摸)
  useEffect(() => {
    const handleMove = (e) => {
      if (isDragging) {
        const { x, y } = getClientPosition(e)
        setPosition({
          x: x - dragOffset.x,
          y: y - dragOffset.y
        })
      }
    }

    const handleEnd = () => setIsDragging(false)

    if (isDragging) {
      document.addEventListener('mousemove', handleMove)
      document.addEventListener('mouseup', handleEnd)
      document.addEventListener('touchmove', handleMove, { passive: false })
      document.addEventListener('touchend', handleEnd)
      document.addEventListener('touchcancel', handleEnd)
    }

    return () => {
      document.removeEventListener('mousemove', handleMove)
      document.removeEventListener('mouseup', handleEnd)
      document.removeEventListener('touchmove', handleMove)
      document.removeEventListener('touchend', handleEnd)
      document.removeEventListener('touchcancel', handleEnd)
    }
  }, [isDragging, dragOffset])

  // 开始拖拽
  const handleStart = (e) => {
    if (e.type === 'touchstart') e.preventDefault()
    const { x, y } = getClientPosition(e)
    setIsDragging(true)
    setDragOffset({
      x: x - position.x,
      y: y - position.y
    })
  }

  // 打开时重置位置
  useEffect(() => {
    if (isOpen) setPosition({ x: 0, y: 0 })
  }, [isOpen])

  if (!isOpen) return null

  return (
    <div className="modal-overlay">
      <div 
        ref={modalRef}
        className="modal-content replay-modal"
        style={{ 
          transform: `translate(${position.x}px, ${position.y}px)`,
          transition: isDragging ? 'none' : 'transform 0.3s ease',
          touchAction: 'none'
        }}
      >
        {/* 可拖拽标题栏 */}
        <div 
          className="modal-drag-handle" 
          onMouseDown={handleStart}
          onTouchStart={handleStart}
        >
          <h2>回放模式</h2>
        </div>
        
        {/* 内容区域 */}
        <div className="replay-info">
          <p>当前步数：{replayIndex + 1} / {moveHistory.length}</p>
          {replayIndex >= 0 && moveHistory[replayIndex] && (
            <p>落子位置：{moveHistory[replayIndex].position.row + 1}行 {moveHistory[replayIndex].position.col + 1}列</p>
          )}
        </div>
        
        {/* 控制按钮 */}
        <div className="replay-controls">
          <button onClick={() => onReplayStep(-1)} disabled={replayIndex < 0}>开始</button>
          <button onClick={onPrevStep} disabled={replayIndex <= 0}>上一步</button>
          <button onClick={onNextStep} disabled={replayIndex >= moveHistory.length - 1}>下一步</button>
          <button onClick={() => onReplayStep(moveHistory.length - 1)} disabled={replayIndex >= moveHistory.length - 1}>结束</button>
        </div>
        
        <button onClick={onClose} className="modal-button">退出回放</button>
      </div>
    </div>
  )
}
```

## 3. 关键技术点

### 3.1 backdrop-filter 浏览器支持

```css
/* 标准属性 */
backdrop-filter: blur(6px);

/* WebKit 内核浏览器 (Safari) */
-webkit-backdrop-filter: blur(6px);

/* 增强饱和度效果 (苹果风格) */
backdrop-filter: saturate(180%) blur(6px);
```

**浏览器支持度**:
- Chrome 76+
- Safari 9+
- Edge 17+
- Firefox 103+

### 3.2 移动端触摸优化

| 技术 | 作用 |
|------|------|
| `touch-action: none` | 禁用默认触摸行为 |
| `passive: false` | 允许阻止默认滚动 |
| `touchstart` 事件 | 触摸开始时触发拖拽 |
| `touchmove` 事件 | 触摸移动时更新位置 |
| `touchend` 事件 | 触摸结束时停止拖拽 |

### 3.3 拖拽算法

```
位置计算公式:
新位置 = 当前位置 - 偏移量 + 鼠标/触摸新位置

dragOffset = 鼠标按下位置 - 模态框当前位置
新位置 = 当前鼠标位置 - dragOffset
```

## 4. 苹果毛玻璃设计原则

### 4.1 设计要点

1. **层次感**: 前景内容层 + 毛玻璃层 + 背景层
2. **模糊程度**: 通常 4-20px，模糊越强越有"厚玻璃"感
3. **透明度**: 0.05-0.3 的低透明度创造微妙的透明效果
4. **边框高光**: 1px 白色半透明边框模拟玻璃边缘
5. **内阴影**: `inset` 阴影增加深度感

### 4.2 配色建议

| 场景 | 背景色 | 模糊值 | 边框 |
|------|--------|--------|------|
| 深色背景 | rgba(255,255,255,0.1) | 10px | rgba(255,255,255,0.2) |
| 浅色背景 | rgba(255,255,255,0.05) | 6px | rgba(255,255,255,0.3) |
| 彩色背景 | rgba(255,255,255,0.15) | 15px | rgba(255,255,255,0.25) |
