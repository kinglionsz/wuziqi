## 三、代码质量修复

### 1. 修复 useOnlineGame.js 闭包问题

**问题**: disconnect 事件处理函数使用了过时的 roomInfo 和 gameState 值

**文件**: `src/hooks/useOnlineGame.js`

**修复方案**: 添加 refs 追踪最新状态

```javascript
// 添加 refs
const roomInfoRef = useRef(roomInfo)
const gameStateRef = useRef(gameState)

// 更新 refs
useEffect(() => {
  roomInfoRef.current = roomInfo
}, [roomInfo])

useEffect(() => {
  gameStateRef.current = gameState
}, [gameState])

// disconnect 事件中使用 refs
socketInstance.on('disconnect', (reason) => {
  const currentRoomInfo = roomInfoRef.current
  const currentGameState = gameStateRef.current
  if (currentRoomInfo && currentRoomInfo.status === 'playing' && !currentGameState.gameOver) {
    setIsReconnecting(true)
    setError('连接断开，正在尝试重连...')
    localStorage.setItem('wuziqi_current_room', currentRoomInfo.roomId)
  }
})
```

