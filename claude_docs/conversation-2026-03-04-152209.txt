  核心问题：异步更新竞态条件

  看 handleCellClick 代码：

   const handleCellClick = useCallback((row, col) => {
     // ...

  问题链条：

   1. 闭包陷阱：board 在依赖数组中，每次 board 更新都会重新创建 handleCellClick
   2. 但：setBoard 和 setMoveHistory 是异步更新
   3. 结果：虽然 handleCellClick 每次都用最新 board 创建，但 moveHistory 保存的 board 可能是落子前的状态，而不是落子后的状态

  为什么是随机的？

   - 正常情况下：board 更新 → handleCellClick 重新创建 → 用最新 board → OK
   - 但在某些情况下（比如快速连续操作）：闭包中的值可能不是预期的

  🛠️ 修复方案

  方案：使用 useRef 追踪最新状态，类似之前修复 AI 落子的方法

   // 添加 ref
   const boardRef = useRef(board)
   const blackTimeRef = useRef(blackTime)
   const whiteTimeRef = useRef(whiteTime)

   // 同步 ref
   useEffect(() => { boardRef.current = board }, [board])
   useEffect(() => { blackTimeRef.current = blackTime }, [blackTime])
   useEffect(() => { whiteTimeRef.current = whiteTime }, [whiteTime])

   // 在 handleCellClick 中使用 ref
   const handleCellClick = useCallback((row, col) => {
     const currentBoard = boardRef.current  // 始终是最新的

     setBoard(newBoard)

     }])
