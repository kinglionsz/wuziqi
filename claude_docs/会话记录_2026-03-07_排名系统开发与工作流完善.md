  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,

  player_name VARCHAR(50) DEFAULT '匿名玩家',
  rating INTEGER DEFAULT 1000,
  games_played INTEGER DEFAULT 0,
  wins INTEGER DEFAULT 0,
  losses INTEGER DEFAULT 0,
  draws INTEGER DEFAULT 0,
  win_streak INTEGER DEFAULT 0,
  max_streak INTEGER DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()

## 阶段 5: Bug 修复 (Supabase 406 错误)

### 问题描述
用户在测试时遇到 HTTP 406 (Not Acceptable) 错误：

```
GET .../player_stats?user_id=eq.device_mmfuxoun_3pg11eg7 406 (Not Acceptable)
```

### 原因分析
Supabase JS SDK 的 `.single()` 方法在查询无结果时返回 HTTP 406 错误。

### 解决方案
将所有 `.single()` 替换为 `.maybeSingle()`：

```javascript
// 错误写法
const { data, error } = await supabase
  .from('player_stats')
  .select('*')
  .eq('user_id', userId)
  .single()  // 无结果时返回 406

// 正确写法
const { data, error } = await supabase
  .from('player_stats')
  .select('*')
  .eq('user_id', userId)
  .maybeSingle()  // 无结果时返回 null
```

### 修改文件
- `src/lib/supabase.js` - 7 处 `.single()` 改为 `.maybeSingle()`
