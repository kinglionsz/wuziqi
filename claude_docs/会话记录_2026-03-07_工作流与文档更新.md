## 完成的工作

### 1. 创建工作流文件

创建了 [`.github/workflows/my-workflow.yml`](../../.github/workflows/my-workflow.yml)

```yaml
name: Wuziqi CI/CD

on:
  workflow_dispatch:
    inputs:
      action:
        description: '执行操作'
        required: true
        default: 'all'
        type: choice
        options:
          - all
          - lint
          - test
          - build
          - deploy
```

**功能**:
- 支持手动触发工作流
- 可选择执行：lint（代码检查）、test（测试）、build（构建）、deploy（部署）或 all（全部）
- 包含代码检查、单元测试、构建和部署到腾讯云的完整流程
