# 五子棋游戏项目 - 架构与部署说明

## 📋 项目概述

- **项目名称**：五子棋游戏
- **作者**：狮王李
- **版本**：v1.2.7
- **技术栈**：React + Vite + Tailwind CSS + Express + Socket.io
- **部署平台**：Railway

## 🏗️ 项目架构

### 1. 技术栈

| 层级 | 技术 |
|------|------|
| **前端框架** | React 18 |
| **构建工具** | Vite |
| **样式** | Tailwind CSS + PostCSS |
| **状态管理** | React Hooks (useState, useEffect, useCallback) |
| **后端通信** | Socket.io-client (WebSocket) |

## 🚀 部署说明

### 前置条件

1. **Railway 账户**：https://railway.app
2. **Supabase 项目**：用于数据存储
3. **后端服务**：已部署的 Socket.io 后端

### 环境变量

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `VITE_SUPABASE_URL` | Supabase 项目 URL | `https://xxx.supabase.co` |
| `VITE_SUPABASE_ANON_KEY` | Supabase 匿名密钥 | `eyJhbGciOiJIUz...` |
| `VITE_SOCKET_URL` | 后端 Socket.io 地址 | `wuziqi-railway-production.up.railway.app` |
| `BACKEND_URL` | 后端 API 地址（服务器端） | `https://wuziqi-railway-production.up.railway.app` |
| `PORT` | 服务端口 | `3000` |

### 部署方式一：Railway CLI

```bash
# 1. 安装依赖
cd railway-frontend
npm install

# 2. 构建前端（可选，dist 已存在）
npm run build

# 3. 登录 Railway
railway login

# 4. 初始化项目（首次部署）
railway init

# 5. 部署
railway up

# 6. 查看日志
railway logs
```

### 部署方式二：Docker

```bash
# 构建镜像
docker build -t wuziqi-frontend .

# 运行容器
docker run -p 3000:3000 \
  -e VITE_SUPABASE_URL=your_url \
  -e VITE_SUPABASE_ANON_KEY=your_key \
  wuziqi-frontend
```

### 部署方式三：GitHub 自动部署

1. 在 Railway 中连接 GitHub 仓库
2. 选择 `railway-frontend` 目录
3. Railway 自动检测配置并部署

## ⚠️ 常见问题

### 1. 构建超时
**原因**：`package.json` 中的 `build` 脚本执行了 `node server.js`

**解决**：确保 `build` 脚本是简单命令：
```json
"build": "echo 'Static site - no build needed'"
```

### 2. API 请求 404
**原因**：代理配置顺序错误

**解决**：确保 `server.js` 中代理在静态文件服务之前：
```javascript
// 先配置代理
app.use('/socket.io', createProxyMiddleware({...}));
app.use('/api', createProxyMiddleware({...}));

// 后配置静态文件
app.use(express.static(...));
```

### 3. 上传文件过小
**原因**：父目录存在 `.railwayignore` 限制

**解决**：删除或修改父目录的 `.railwayignore` 文件

## 📝 关键文件说明

### server.js
Express 服务器，提供：
- 静态文件服务（`dist/` 目录）
- WebSocket 代理（`/socket.io`）
- API 代理（`/api`）
- CORS 支持
- 健康检查端点（`/health`）

### Dockerfile
多阶段构建：
1. 阶段 1：安装依赖并构建
2. 阶段 2：使用 Nginx 提供静态文件服务

### railway.json
Railway 部署配置：
- 构建命令：`npm install && npm run build`
- 启动命令：`node server.js`
