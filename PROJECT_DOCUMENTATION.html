项目概述

本项目是一个功能完整的五子棋在线游戏，采用前后端分离架构，支持三种游戏模式：双人本地对战(PVP) 人机对战(PVE) 在线对战。项目使用 React + Vite 构建前端，Node.js + Express + Socket.io 构建后端服务，部署于腾讯云 CloudBase 平台。

✨ 项目特点

核心功能

  • 三种游戏模式 - PVP双人本地对战、PVE人机对战、ONLINE在线对战
  • 六种主题皮肤 - 默认、木质、海洋、森林、夜间、粉色
  • 智能AI对手 - 多种难度级别的人机对战体验
  • 实时在线对战 - 基于WebSocket的实时通信，支持房间创建和加入
  • 游戏记录保存 - 本地存储和云端同步游戏记录
  • 丰富音效 - 落子音效、胜利音效、可调节音量

前端特性

  • React 19 + Vite 7 现代前端架构
  • Tailwind CSS 4 响应式样式方案
  • 15×15 标准五子棋棋盘
  • 六种精美主题皮肤
  • 棋子动画和最后落子标记

后端特性

  • Node.js + Express 后端服务
  • Socket.io 实时通信
  • CloudBase 云托管部署
  • NoSQL 数据库存储
  • 房间管理系统

❓ 常见问题

Q1: 如何开始游戏？

打开游戏后，选择三种游戏模式之一：PVP（双人本地对战）、PVE（人机对战）或 ONLINE（在线对战）。选择后即可开始游戏。

Q2: 如何进行在线对战？

选择 ONLINE 模式后，可以选择"创建房间"生成房间号发送给朋友，或输入房间号"加入房间"与朋友对战。

Q3: 如何切换主题？

点击设置按钮，在主题选项中选择喜欢的皮肤：默认、木质、海洋、森林、夜间、粉色。

Q4: 游戏记录在哪里查看？

游戏结束后会自动保存记录到本地存储和云端，可以在设置中查看游戏历史记录。

Q5: 部署遇到问题怎么办？

请确保 Node.js 版本 >= 18.0.0，Docker 版本 >= 20.10.0。如遇问题，可查看控制台日志或联系技术支持。

Q6: 如何本地开发调试？

# 启动前端开发服务器
npm run dev

# 启动后端服务
cd cloudbase/server
node server.js
